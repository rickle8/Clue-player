# Clue Player

A companion app for tracking deductions while playing Clue. Log each guess and the scorecard works out who holds which cards and what's in the envelope.

**Open the app:** https://rickle8.github.io/Clue-player/

On iPhone: open the link in Safari, tap Share, then **Add to Home Screen**.

Saved games stay in your own phone's browser; nothing is uploaded.

This repo holds only the built web app (Flutter). Keep the repo named `Clue-player`; the app expects that path.
